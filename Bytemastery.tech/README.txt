# Bytemastery.tech

This project demonstrates sending Ethereum on the blockchain tagged with a message and keyword gif to any wallet in the world. This Web3.0 application uses MetaMask pairing to retrieve wallet data, latest transactions, along with React.js framework for GIPHY api fetching, and sending Ethereum through the mainnet. Go ahead, try it out!
